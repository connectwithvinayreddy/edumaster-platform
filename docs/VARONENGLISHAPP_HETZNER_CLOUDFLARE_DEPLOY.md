# `varonenglishapp.in` Deployment Guide

This guide is the shortest safe path to deploy EduMaster on:

- `GoDaddy` for domain ownership
- `Cloudflare` for DNS, SSL, and CDN
- `Hetzner` for app hosting
- `Cloudflare R2` for replay and protected video storage

## 1. Prepare the domain

In GoDaddy:

1. Open `varonenglishapp.in`.
2. Turn on `Auto-renew`.
3. Change nameservers to the two nameservers shown by Cloudflare.

In Cloudflare:

1. Add the site `varonenglishapp.in`.
2. Wait until the zone becomes active.
3. Open `DNS` and create:
   - `A` record `app` -> `YOUR_HETZNER_SERVER_IP`
   - `A` record `live` -> `YOUR_HETZNER_SERVER_IP`
4. Leave the proxy enabled for both records.

## 2. Prepare the server

Create a Hetzner Ubuntu server with at least:

- `8 vCPU`
- `16 GB RAM`
- `160 GB SSD`

Open these ports in the Hetzner firewall:

- `22`
- `80`
- `443`
- `1935`

Install Docker and the Compose plugin:

```bash
apt update
apt install -y ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
systemctl enable docker
systemctl start docker
```

## 3. Prepare Cloudflare R2

In Cloudflare:

1. Open `R2`.
2. Create a bucket, for example `edumaster-replays`.
3. Create an API token or access key with bucket access.
4. Copy:
   - bucket name
   - account ID
   - access key ID
   - secret access key

## 4. Create production env

Copy the domain-specific template:

```bash
cp .env.production.varonenglishapp.template .env.production
```

Generate secrets:

```bash
npm run secrets:production
```

Paste the generated values into `.env.production`.

Then fill these placeholders:

- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`
- `REPLAY_IMPORT_ADMIN_EMAIL`
- `REPLAY_IMPORT_ADMIN_PASSWORD`
- `S3_BUCKET`
- `S3_ACCESS_KEY_ID`
- `S3_SECRET_ACCESS_KEY`
- `S3_ENDPOINT`
- optional LiveKit values if you want interactive classes

## 5. Validate production config

Run:

```bash
npm run validate:production
npm run build
```

Production validation must pass before deployment.

## 6. Deploy to Hetzner

From your local machine:

```bash
chmod +x infra/lowcost/deploy-hetzner.sh
./infra/lowcost/deploy-hetzner.sh root@YOUR_HETZNER_SERVER_IP /opt/edumaster
```

This will:

1. validate env
2. build the frontend
3. sync the repo to the server
4. start the production Docker Compose stack

## 7. Verify the app

Open:

- `https://app.varonenglishapp.in/healthz`
- `https://app.varonenglishapp.in/backend/api/health`

If both respond correctly, log into the app and test admin flows.

## 8. Verify live streaming

OBS settings:

- `Server`: `rtmp://live.varonenglishapp.in:1935/live`
- `Stream key`: generated by the app for the live class
- `Keyframe interval`: `2`
- `FPS`: `30`
- `Video bitrate`: `2500-3500 kbps`

Student playback should come from `https://live.varonenglishapp.in/hls/...`.

## 9. Important safety notes

- Do not commit `.env.production`.
- Rotate any existing secrets that were previously saved in local env files.
- Keep lesson and live video delivery off the main app backend path for better playback under load.
